# Miharashi

Miharashi（ミハラシ）は、Rustで実装するLinux専用キオスク・ダッシュボードです。このフォルダには実装前の仕様・設計・LPを収録しています。

リポジトリ名・実行ファイル名は `miharashi`、予定するsystemdユニット名は `miharashi.service` に統一します。CPU/GPUの型番、搭載メモリ容量、デバイス番号を特定の利用環境に固定しません。

現段階ではRustアプリの実装・ビルド・実機KMS検証は行っていません。LPの画面と数値はコンセプトプレビューです。

## LPの表示

`site/index.html` をブラウザーで開けます。外部フォント・画像・CDNへの接続は不要です。

ローカルサーバーを使う場合は、プロジェクトフォルダで次を実行します。

```sh
python3 -m http.server 18765 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:18765/site/` を開きます。ポートが使用中なら別の空きポートに変えてください。

プレビュー内の4/6で画面切替、0でメニュー、5で詳細表示を試せます。FAQは見出しをクリックして開きます。このブラウザー内の操作例は、Linux evdevの動作確認を意味しません。

## 次の実装順序

1. Rustワークスペースと共通RGBAレンダラーを作る。
2. 3画面のPNG出力を通してコンパイル・ヘッドレス検証を行う。
3. 非同期のシステム収集・交換可能なエージェントAdapter・evdevを接続する。
4. libseatによるlogind/seatd管理と直接DRM/KMSを統合する。
5. 対象Linux環境で表示デバイス選択、VT切替、権限、systemd自動起動を検証する。

PRDは要件の基準、技術設計書は実装案です。実機で未検証の項目を実装済みとして扱わず、結果が出た段階で文書を更新します。
