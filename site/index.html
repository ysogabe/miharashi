02 / Features

眺めるだけで、
家とサーバーの様子が分かる。

自宅の場所が分かる画面は、
画像を載せていません。

ALERTS

地震と災害を、どの画面の上にも

住んでいる地方で震度 4 以上、全国で震度 5 弱以上の地震は、震源と震度の地図を重ねて知らせます。自宅から 50km 以内に特別警報や土砂災害危険警報が出たときも同じです。データは気象庁。

PHOTOS

旅ごと、季節ごとに写真を流す

写真の撮影地から、自宅を離れた「旅」と、いつもの暮らしの「季節」に分けて巡回します。区切りには、行き先の地図と日付のカードを挟みます。

AIRCRAFT

上空を飛ぶ航空機

ADS-B 受信機(readsb)の情報から、近くを飛ぶ機体を近い順に並べ、機種・登録記号・運航会社・経路を表示します。今は写真の合間に挟んでいて、独立した画面に作り直す予定です。

SCREEN POWER

留守ならモニターを消す

Home Assistant の在宅判定で、不在が続けば消灯し、帰れば点灯します。アラートは消灯中でも点けて見せます。手動の「常に点灯 / 常に消灯」も切り替えられます。

REMOTE

手元の Echo Show 5 から操作

Android 化した Echo Show 5 が、専用の操作盤になります。画面の切替と、モニターの消灯・点灯・自動。今どの画面かも手元で分かります。

LIGHTWEIGHT

内蔵 GPU で描いて、CPU を空ける

写真の拡大・ぼかし・重ね合わせは内蔵 GPU(OpenGL ES 3.2)で行い、写真画面でも CPU 使用率は 1% 前後です。サーバー本来の仕事の邪魔をしません。

03 / Control panel

テンキーでも、
手元の画面からでも。

Miharashi はテンキーの 4 / 5 / 6 で操作します。机の上の Echo Show 5 に専用アプリを入れれば、同じ操作を大きなボタンで送れます。

  • 今の画面名、ページ、写真の何枚目かを手元に表示
  • モニターの消灯・点灯・自動を、Home Assistant と連動して切替
  • しばらく触らなければ操作盤も消灯し、触れば点灯

DEVICE ROLES

表示する GPU と、見張る GPU を分けられる。

表示は内蔵 GPU、計算は別の GPU、という構成でも、1 枚の GPU の構成でも動きます。表示先のカードとコネクター、監視する GPU は設定で選びます。GPU が使えなければ CPU 描画に戻ります。

SEAT & SYSTEMD

root ではなく、一般ユーザーで常駐。

logind の seat から表示と入力のデバイスを受け取り、VT を切り替えれば手放して、戻れば復帰します。systemd で起動し、落ちても自動で立ち上がります。12 時間の連続試験に合格しています。

06 / FAQ

よくある質問

作っている側が、
聞かれそうだと思った質問です。

ターミナル上で動く TUI ですか？

いいえ。TUI 風の見た目ですが、ピクセル単位で描く全画面のアプリです。文字・写真・グラフを同じ画面に描きます。

X11 や Wayland、ウィンドウマネージャーは必要ですか？

要りません。Linux の DRM/KMS へ直接描きます。デスクトップ環境の無いサーバーでも、モニターをつなげば表示できます。

どんなハードウェアで動きますか？

Linux で DRM/KMS が使える GPU があれば動きます。作者の実機は、表示に CPU 内蔵の GPU を使い、計算用に別の GPU を積んだ構成です。特定の型番やメモリ容量を前提にはしていません。

CPU や GPU の温度・電力は、すべて取れますか？

ドライバーやセンサーが値を出していれば表示します。出ていない値は「--」になります。CPU の電力は RAPL からの推定値で、システム全体の消費電力ではありません。

テンキーが無くても使えますか？

使えます。操作パネルを有効にしていれば、キーボードが無くても起動し、あとから挿されたテンキーも自動で使い始めます。

写真はどこから表示しますか？

GEOFRAME(自宅の写真サーバー)から取得します。1 枚のファイルを指定して表示することもできます。

Home Assistant が止まったら、モニターは消えたままになりますか？

なりません。Home Assistant と通信できないときは点灯させておきます。手動の「常に消灯」も、通信できない状態が続けば自動に戻ります。

自分の環境でも使えますか？

ソースは公開していますが、今は作者の環境で毎日使いながら育てている段階です。表示先や監視対象は設定で変えられるようにしています。
